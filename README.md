# Дашборд нагрузки преподавателей

Рабочий MVP для онлайн-школы: преподаватели фиксируют занятия, а руководитель видит общую нагрузку и статистику команды. Первая версия была собрана за 3 дня, затем доработана по обратной связи руководителя. Решением пользовались 16 преподавателей.

> Публичная демонстрация с рабочими данными не размещена, чтобы не раскрывать информацию онлайн-школы.

## Задача

Руководителю требовалось в одном месте видеть загрузку преподавателей, а сотрудникам — быстро добавлять занятия и отмечать их результат без внедрения сложной CRM.

## Решение

```text
Преподаватель / руководитель
            ↓
      веб-интерфейс
            ↓
     Google Apps Script
            ↓
       Google Sheets
```

Google Таблицы используются как понятное заказчику хранилище данных, Google Apps Script — как API, а статический интерфейс публикуется через GitHub Pages.

## Возможности

### Для преподавателя

- вход по имени и PIN-коду;
- добавление занятия с учеником, датой и временем;
- просмотр собственных занятий;
- изменение статуса: запланировано, проведено или отменено;
- комментарии к занятиям.

### Для руководителя

- сводная статистика по команде;
- количество запланированных, проведённых и отменённых занятий;
- индикатор потенциальной перегрузки;
- общий список занятий и фильтры по статусам;
- внутренние комментарии по преподавателям.

## Результат

- MVP внедрён в рабочий процесс онлайн-школы;

## Локальный запуск

Интерфейс не требует сборки. Для локального просмотра можно запустить простой HTTP-сервер:

```bash
git clone https://github.com/by-maxb/teachers-workload.git
cd teachers-workload
python -m http.server 8000
```

Для полноценной работы с данными потребуется собственная Google Таблица и отдельное развёртывание `apps-script/Code.gs` как Apps Script Web App.

## Ограничения текущего MVP

Текущая версия рассчитана на небольшой внутренний процесс и использует упрощённую авторизацию по имени и PIN-коду. Для промышленной эксплуатации потребуются полноценные учётные записи, усиленная серверная проверка прав доступа, безопасная передача изменяющих запросов, журналирование действий и отдельная тестовая среда.

В репозитории не должны храниться реальные имена преподавателей и учеников, PIN-коды или выгрузки рабочей таблицы.
